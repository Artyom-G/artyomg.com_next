# Project Overview

Chord-It is a chord switching game for beginner guitarists who can play a few chords but struggle to change between them in time.

I'm learning guitar myself, and the hardest part so far hasn't been learning new chords. It's been moving between them without stopping the song. The apps I found were either full lesson platforms or chord libraries, and none of them simply drilled chord changes the way I wanted. So I built one: pick your chords, set a tempo, and Chord-It calls out the next chord on the beat.

# Try Me

Pick a few chords, press **Start** (turn your sound on), and try to keep up!

# Key Features

**Chords by level:** Beginner, intermediate and advanced chords, from open A, D, E and G up to full barre chords.

**Practise a key:** One tap loads the everyday chords of a key, so you practise changes that actually show up in songs.

**Metronome and count-in:** Set the tempo and how often the chord changes. Each round starts with a count-in: *Ready? → Bop-It → Twist-It → Chord-It!*

**Guitar and piano diagrams:** See where your fingers go, along with the notes that make up each chord.

**Your fingering:** Some chords can be played in more than one way. Pick the one that works for you, and Chord-It remembers it.

# Why Retro?

Practising the same changes over and over gets repetitive, so I wanted it to feel like a game rather than an exercise. Chord-It is styled like a 1970s hi-fi deck, with a glowing amber display and chunky buttons.
