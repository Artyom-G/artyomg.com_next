# Project Overview

Free For All is a 2D pixel-art local multiplayer deathmatch for 2 to 4 players. Pick one of 8 playable characters, including a goat, a tank and a blob, and fight across 4 completely different maps. The last one standing earns a crown.

# Technologies Used

**Unity:** Game engine for the 2D physics, local multiplayer input and the Windows build.

**C#:** Character abilities, weapons, health and the scoreboard.

# Key Features

- **8 characters, 4 maps:** Each character has a primary and a secondary weapon.
- **Local multiplayer:** 2 to 4 players on one keyboard, with full gamepad support and configurable controls.
- **Pixel art:** Pixel-art characters and maps.
