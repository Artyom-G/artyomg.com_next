# Project Overview

Roll 3310 is a 3D platformer I made solo for the **Nokia 3310 Jam 2**, a game jam where every entry has to look like it could run on the classic Nokia 3310's two-tone screen. You roll a ball through a grid-lined world rendered in the jam's limited palette, using a toon shader to keep the 3D scenes readable in just two colors.

# Technologies Used

**Unity:** Game engine for the 3D physics, level design and WebGL build.

**C#:** Gameplay scripting.

**Toon Shader:** A free toon shader for the flat, two-color look.

# Key Features

- **3D in two colors:** A full 3D platformer squeezed into the Nokia 3310's retro palette.
- **Physics-based movement:** The player controls a rolling ball rather than a character.
- **Playable in the browser:** Released for HTML5 and Windows.
