# Project Overview

Calculator Snake is my solo submission for **Brain JAM**, a game jam with the theme *"Calculate"*. I took the theme literally and built a playable game inside a calculator: the classic Snake, running on the screen of a hand-drawn graphing calculator.

# Technologies Used

**Unity:** Game engine for the gameplay and the HTML5 and Windows builds.

**C#:** Game logic for the snake, food spawning and scoring.

# Key Features

- **Game inside a device:** Snake is played on the calculator's LCD, framed by the calculator itself.
- **Original art:** All graphics and code were made by me; sound effects are from ZapSplat.
